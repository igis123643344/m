# maimaiレート計算（maimai でらっくす レート計算・記録アプリ）

個人用の Web アプリ（PWA）です。データはすべてスマホの中に保存されます。

## GitHub Pages で公開する手順（パソコンで約10分）

1. https://github.com でアカウントを作成してログインします。
2. 右上の「＋」→「New repository」を選びます。
   - Repository name：`rate-note`（好きな名前でOK）
   - **Public** を選択（無料プランで Pages を使うのに必要です。公開されるのはアプリの部品だけで、あなたの記録は含まれません）
   - 「Create repository」を押します。
3. 作成直後の画面で「uploading an existing file」をクリックします。
4. この zip を展開したフォルダの**中身すべて**（`index.html`、`js`、`vendor`、`icons` など）をブラウザにドラッグ＆ドロップし、下の「Commit changes」を押します。
5. リポジトリの「Settings」→ 左メニュー「Pages」を開きます。
   - Source：「Deploy from a branch」
   - Branch：`main` / `/(root)` →「Save」
6. 1〜2分待つと、`https://<ユーザー名>.github.io/rate-note/` で開けるようになります。

## スマホ（Android）に入れる

1. Chrome で上の URL を開きます。
2. 右上の「⋮」→「アプリをインストール」（または「ホーム画面に追加」）を選びます。
3. 初回起動時に曲データ（譜面定数）を自動で読み込みます。

## 過去のベ枠を入れる（最初の1回だけ）

1. `rate-note-import-past-versions.json` をスマホに保存します（Google ドライブ経由など）。
2. アプリの「設定」→「バックアップから復元」でそのファイルを選びます。

## データを失わないために

- ホーム画面に追加すると、ブラウザの「消去防止」が有効になりやすくなります（設定タブで状態を確認できます）。
- 設定タブの「共有して保存」→ Google ドライブ で、時々バックアップを取ってください（14日以上空くとお知らせが出ます）。
- 機種変更のときは、新しいスマホで「バックアップから復元」を使います。

## アプリを更新するとき

新しいファイルを同じリポジトリにもう一度アップロード（上書き）すれば、次にアプリを開いたときに反映されます。記録は消えません。

## 仕組み

- 計算：単曲レート = 切り捨て(譜面定数 × 係数 × 達成率)（達成率の上限は 100.5%）、合計 = 旧曲ベスト35 + 新曲ベスト15
- 譜面定数：有志データベース otoge-db（https://github.com/zvuc/otoge-db）のデータを1日1回取得
- 写真の読み取り：Tesseract.js（スマホ内で処理し、写真は外部に送られません）
